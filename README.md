# The Mainalon GitHub Pages Website

## Publish on GitHub Pages

1. Create a public repository named `yourusername.github.io`.
2. Upload everything inside this folder, keeping the `assets` and `articles` folders.
3. Commit the files.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Choose `main` and `/ (root)`.

## Before launch

- Replace sample copy and photos.
- Replace the contact email if needed.
- The newsletter form is visual only.
- Replace the placeholder privacy policy before using ads, analytics, email marketing or payments.
- External Unsplash images are temporary placeholders; use your own images for the final site.

## Custom domain

After the GitHub site works, enter `themainalon.com` in GitHub **Settings → Pages → Custom domain**, then update the DNS records in GoDaddy.
